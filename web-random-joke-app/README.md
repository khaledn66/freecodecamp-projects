# Random Joke Server

A simple random joke web application built with Node.js and Express.js.

The application provides a small web interface where users can click a button to receive a random programming joke.

## Features

- Random programming jokes
- Simple web interface
- Express.js backend
- HTML and CSS frontend
- API endpoint for random jokes
- Responsive and clean design

## Technologies

- Node.js
- Express.js
- HTML
- CSS
- JavaScript
