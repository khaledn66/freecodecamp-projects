# Build a File Processor in Node.js

A Node.js project created as part of my FreeCodeCamp coursework.

The project demonstrates working with files, streams, buffers, system information, paths, processes, and cryptographic functions using built-in Node.js modules.

## Features

The project includes examples of:

* Reading files with `fs/promises`
* Creating and writing files with `fs`
* Appending data to files
* Checking whether a file exists
* Reading directory contents
* Working with `Buffer`
* Encoding and decoding Base64 and hexadecimal data
* Creating SHA-256 hashes
* Generating random bytes and UUIDs
* Getting operating system information with `os`
* Working with file paths using `path`
* Accessing Node.js process information with `process`
* Using command-line arguments
* Writing to `stdout` and `stderr`
* Reading and writing files with streams
* Using streams with `pipe()`

## Requirements

* Node.js

## How to Run

Clone the repository, navigate to the project directory, and run:

```bash
node server.js
```

The program reads and writes files in the `assets` directory and prints various results to the console.
